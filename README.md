# AI ROADMAP

AI ROADMAP est une plateforme immersive pour apprendre l’intelligence artificielle de zéro à expert.

## Concept

L’utilisateur entre dans un univers interactif, choisit son chemin, débloque des compétences, réalise des missions et construit progressivement son profil d’expert.

## Slogan

Beoogo Bangre — De zéro à expert. Une compétence à la fois.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Three.js / React Three Fiber
- Zustand
- Supabase

## Lancer le projet

```bash
npm install
